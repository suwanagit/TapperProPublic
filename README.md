# Tapper Pro for Mac

Karaoke video maker. Installing takes about one minute.
โปรแกรมทำวิดีโอคาราโอเกะ ติดตั้งประมาณ 1 นาที

## Install or update / ติดตั้งหรืออัปเดต

**1.** Press **⌘ Command + Space**, type **Terminal**, press **Return**.
กดปุ่ม **⌘ Command + Space** พิมพ์ **Terminal** แล้วกด **Return**

**2.** Copy this line, paste it into the Terminal window (**⌘ Command + V**), and press **Return**:
คัดลอกบรรทัดนี้ วางในหน้าต่าง Terminal (**⌘ Command + V**) แล้วกด **Return**

```
curl -fsSL https://raw.githubusercontent.com/suwanagit/TapperProPublic/main/install.sh | bash
```

**3.** Wait until it says **Done!** Tapper Pro opens by itself. Close the Terminal window.
รอจนขึ้นว่า **Done!** แล้ว Tapper Pro จะเปิดขึ้นเอง ปิดหน้าต่าง Terminal ได้เลย

From now on, open Tapper Pro from **Launchpad** (or the **Applications** folder).
ครั้งต่อไปเปิด Tapper Pro จาก **Launchpad** (หรือโฟลเดอร์ **Applications**)

To update to a newer version later, do the same three steps again. Your projects are kept.
ถ้ามีเวอร์ชันใหม่ ให้ทำ 3 ขั้นตอนนี้อีกครั้ง โปรเจกต์ของคุณจะไม่หาย
